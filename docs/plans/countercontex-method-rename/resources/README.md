# Resources

Shared reference material for this plan. Create only what the plan actually needs --
this directory is not prescriptive. Delete this README once real files exist.

Common files: `queries.md` (investigation queries), `commands.md` (build/test/deploy),
`configs.md` (env vars, feature flags), `data.md` (fixtures, seed values).

Use placeholders (`{schema}`, `{env}`, `${API_URL}`) so material stays portable.
